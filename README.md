# 素材库 · 个人本地版 1.2.0

Windows 桌面应用，启动直接进入素材库，无需账号、密码、NAS、Docker 或其他电脑。不连接原团队素材库。

## 使用

1. 在完整程序文件夹中运行「素材库.exe」，不要只复制 exe。
2. 点击左侧「文件夹」旁的 ＋，在侧边栏直接输入名称，Enter 保存，Esc 取消。失焦也会保存非空名称。
3. 右键文件夹或点击悬停出现的 …：新增文件夹创建同级，新增子文件夹创建下级；可重命名、移动、展开/收起自身、同级或全部，以及选择图标和颜色。F2 重命名，Ctrl+Shift+N 新建同级，Alt+N 新建子文件夹。删除会二次确认并保留素材。移动不能放入自身或下级，不覆盖同名文件夹。右键空白处可以新建顶级文件夹。
4. 拖入文件或整个文件夹、点击「导入素材」/「导入文件夹」，或用 Ctrl+V 粘贴图片。文件夹会递归扫描图片与视频，并在当前分类下保留文件夹层级；同级同名分类复用。原文件复制进素材库，导入来源不会自动删除。相同内容按 SHA-256 去重。压缩包不会自动解压。
5. 左下角齿轮打开本地设置，选择新的空文件夹，再点「确认迁移整个素材库」。原图、视频、分类、标签、评分、备注和回收站记录一并迁移；缩略图可重新生成。

Ctrl+滚轮调整缩略图大小。空格预览，左右键切换，Esc 关闭。大图保持圆角，下方模糊衬底来自下一张素材。

侧边栏按住文件夹约 350 毫秒，再拖到另一个文件夹上，目标高亮后松开，即成为其子文件夹；原有下级和素材归属保留。不能拖入自身或自己的下级。移动到顶级仍可使用右键「移动文件夹」。

本轮开发版已由用户确认，发布 Windows 便携文件夹与压缩包。

## 存储与迁移

默认库目录：`%APPDATA%/personal-asset-library/library`。实际路径以左下角设置为准。

- `database/library.sqlite` 保存分类、标签、评分、备注等信息。
- `database/thumbs` 保存缩略图缓存。
- `media` 保存软件管理的原文件，请勿手工改名或移动内部文件。
- 用户配置在 `%APPDATA%/personal-asset-library/config/desktop.json`。

迁移目标需为空的本机目录，不能与旧库相同、包含旧库或位于旧库内。程序会锁定写入、保存数据库快照、复制并核对每个原文件的 SHA-256，再切换配置。失败时继续使用旧库，目标中可能留下未完成副本，需要手动清理后重试。

旧库不会自动删除，迁移期间需要额外容量。先确认新位置的数据完整并可重启读取，再决定是否清理旧库。旧库是切换前副本，切换后不会继续同步；迁移元数据快照也不能独立替代包含原文件的完整备份。独立备份请在退出应用后复制整个库目录。

程序关闭即退出。没有登录页面、多人账号、网络共享入口或浏览器版。

## 开发

建议 Node.js 24，依赖以 package-lock.json 为准：

```powershell
npm ci
npm run build:ui
npm test
npm run test:personal
npm start
npm run package
```

测试通过 `ASSET_CONFIG_DIR`、`ASSET_LIBRARY_DIR` 使用隔离目录；不要把测试路径用于日常库。源码不包含 node_modules 或个人素材数据。

视频导入、播放能力取决于编码格式；视频封面和信息读取需要本机可调用 FFmpeg/FFprobe，程序未内置这两个工具。

第三方组件、修改及许可见 OPEN_SOURCE.md 和 licenses/。

本版 Windows 程序部署在 `D:\素材库`。程序位置与素材库位置独立；升级保留既有个人库配置，实际素材路径仍以设置为准。

## 1.1.2 加载动画与回收站选择

- 缩略图生成和实际图片加载期间显示既有 LatticeLoader，仅保留格点动画，不显示可见文字；读屏状态保留。格点本身以图片区域为基准水平、垂直居中，载入完成即移除，失败时显示静态错误信息。
- 回收站新增「全部选择」「全部取消」，全选包含当前筛选条件下未加载的项目。清空或切换筛选会取消过期选择请求。批量恢复与彻底删除按每批最多 200 项串行提交；失败时刷新实际状态。
- thumbnail-loading.cjs 验证动画存在且时间推进、图片区域居中、完成后消失、失败不继续转动；trash-selection.cjs 用 205 条元数据测试跨页全选、取消与分批恢复。测试不操作实际用户库。

## 1.1.3 快速选择

所有素材浏览页均提供「全部选择」「全部取消」，全选覆盖当前文件夹和筛选条件下尚未加载的项目。Ctrl+A 同样按当前范围全选。按住 Ctrl＋鼠标左键可以追加或取消单项；不按 Ctrl 的普通单击仍为单选，保留既有 Shift 范围选择。Ctrl 多选使用状态更新函数，避免连续点击时使用旧选择状态。超过 200 项的批量评分、标签、分类和移入回收站按每批 200 项处理。
